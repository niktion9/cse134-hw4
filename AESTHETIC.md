# Botanical Field Journal

**Selected Aesthetic:** Naturecore / Botanical Field Journal

## Design Choices

For this project I chose a Botanical Field Journal aesthetic because I wanted the website to feel like an old naturalist's notebook. I used warm cream and parchment colors for the background, muted greens for headings and accents, and earthy browns for borders. The typography switches to a classic serif typeface that resembles printed field guides, while rounded image borders and soft shadows make the illustrations feel like specimens collected in a journal rather than ordinary website graphics. These choices create a calm, natural atmosphere while keeping the content easy to read.

## JavaScript Enhancement

I added a **Field Journal Mode** toggle. When the button is pressed, JavaScript adds or removes a CSS class on the page to activate the Botanical Field Journal theme. The interaction uses an external JavaScript file, `querySelector()`, `addEventListener()`, DOM class manipulation, and `localStorage` so the user's preference is remembered between visits. If JavaScript is disabled, the website still displays all of its content using the default theme.

## Accessibility and Responsiveness

To preserve usability, I kept the original semantic HTML structure and ensured that the content remains readable at both desktop and mobile widths. The toggle is a real `<button>` with an updated `aria-pressed` state, keyboard users can still navigate the page, and the design keeps strong color contrast so text remains easy to read.

## The Medium Is the Message

Marshall McLuhan argues that the way information is presented changes how people experience it. My Botanical Field Journal design changes the feeling of the website without changing its content. Instead of appearing as a simple informational webpage, the Cheese Society feels like a collection of observations from a naturalist documenting different cheeses in the field. The colors, typography, textures, and interaction encourage visitors to slow down and explore, making the design itself part of the message. The website communicates curiosity, discovery, and appreciation for nature through its presentation rather than through words alone.
